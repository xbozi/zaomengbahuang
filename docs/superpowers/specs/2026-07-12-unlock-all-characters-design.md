# 角色选择全量开放设计

## 目标

角色选择页始终展示并允许选择悟空、唐僧、猪八戒、沙悟净和小白龙。该行为同时适用于新建存档和已有存档。

## 方案

修改 `Script/Main_menu/ChoosePlayer.gd` 的 `_ready()` 初始化流程，将角色代码列表固定为 `swk`、`tsz`、`zbj`、`swj`、`xbl`。删除基于 `MainSet.set_data` 中 `LevelHYS`、`LevelTT` 和 `XiaoBaiLong` 字段向列表追加角色的条件。

角色按钮仍沿用现有的 `Global.AddRoleButton()` 创建方式。选择确认后，现有的存档绑定、角色 ID 写入和地图跳转逻辑不变。

## 兼容性

此改动不修改存档结构，也不读取或迁移历史存档；角色列表不再依赖解锁进度，因此已有存档打开选择页时同样可选择全部五名角色。原有通关后的“解锁角色”提示保留，但不再控制角色是否显示。

## 验证

项目未配置自动化测试框架。实现后将核验角色列表包含且仅包含五个预期代码，并检查差异范围只影响角色选择的初始化逻辑。
